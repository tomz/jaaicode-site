# jaaicode

**Just Another AI Coder** — a terminal-first AI coding assistant. Works
with local Ollama models and any OpenAI-compatible API (LiteLLM,
OpenAI, Anthropic, Google, …). Streaming responses, autonomous tool
use, Rich markdown rendering.

## Quick install

```bash
curl -fsSL https://jaaicode.org/install.sh | sh
```

Works on macOS (Intel + Apple Silicon) and Linux without an existing
Python, Homebrew, or Xcode toolchain — the installer brings its own
runtime if needed.

Then just:

```bash
jaaicode
```
